Repositorio de estudio para el curso de **Minería de Datos**, con los principales conceptos teóricos vistos en clase, ejemplos y código explicado.

---

## 📚 Contenido

### 1. Introducción a la Minería de Datos

- Concepto y objetivo de la minería de datos.
- Importancia y aplicaciones en diferentes áreas.
- Modelos de proceso de minería de datos.
- KDD, SEMMA, TDSP, Guerrilla Analytics y CRISP-DM.
- Tipos de problemas de minería de datos.

### 2. Metodología CRISP-DM

- Concepto y estructura de CRISP-DM.
- Comprensión del negocio.
- Comprensión de los datos.
- Objetivos, tareas y resultados de cada fase estudiada.

### 3. Datos y tipos de variables

- Variables cuantitativas y cualitativas.
- Variables discretas, continuas, nominales y ordinales.
- Código disyuntivo completo.
- Valores nulos y valores atípicos.
- Diagramas de caja y cuartiles.

### 4. Reducción de dimensionalidad y análisis de clústeres

- Reducción de dimensiones.
- Análisis de Componentes Principales (PCA).
- Clustering o clasificación no supervisada.
- Clustering jerárquico.
- K-means.
- Método del codo.
- Ventajas y limitaciones del agrupamiento.

### 5. Modelos predictivos y regresión

- Concepto de modelo predictivo.
- Regresión lineal simple.
- Regresión lineal múltiple.
- Regresión logística.
- Variables predictoras y variables respuesta.
- Interpretación general de los modelos.

### 6. Código explicado y conceptos prácticos

- Carga y exploración de datos con Pandas.
- Estadísticas descriptivas.
- Media, mediana, desviación estándar y cuantiles.
- Tablas de frecuencia y contingencia.
- Gráficos de barras.
- Boxplots.
- Histogramas y gráficos de densidad.
- Pairplots y análisis de relaciones entre variables.
- Relación del código con la fase de comprensión de datos de CRISP-DM.
